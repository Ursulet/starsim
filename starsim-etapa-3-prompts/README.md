# Star Sim — Etapa 3 Prompts

Etapa 3 construiește interfața publică completă, fidelă mockup-ului, folosind conținutul din CMS/admin creat în Etapele 1–2.

Reguli:
- Nu adăuga prompturi de testing.
- Nu schimba stack-ul.
- Nu transforma designul într-un template generic.
- Respectă mockup-ul Star Sim: alb, navy, gold, emoțional, astronomic, curat.
- Homepage-ul rămâne scurt și controlat: Header → Hero → Misiune → Programe → Evenimente → Fiecare gest contează → Footer.
- Galeria, contactul extins, articolele și paginile secundare merg pe rutele lor dedicate.
- Datele vin din PostgreSQL prin Prisma, cu fallback minimal doar unde este strict necesar pentru development.
- Public pages trebuie să fie SEO-ready, rapide și responsive.
- Lasă testarea pe seama beneficiarului; nu scrie instrucțiuni sau fișiere de test.
